One word for the whole internet, written for make.fun's
**The Internet in One Word** bounty. The program writes a single word
of at most 30 characters to `/output/entry.txt`.

## The word

> Doomscroll

10 characters, one word. Not the first obvious answer — "procrastination"
is what people do *on* the internet, and it could describe a messy desk
just as well. Doomscroll is the internet's own native verb: funny by
itself, true of the whole internet rather than one app (every feed, every
timeline, every "just one more" is the same endless scroll), and it
surprises, because it is a word the internet invented for the act of
drowning in it. It lands in one beat — ten letters, instantly readable —
and makes the reader laugh, then nod: the whole internet, in the end, is
one long doomscroll.

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network. Deterministic: every run
writes the same bytes. The output directory is `/output` by default, or
`$MAKEFUN_OUTPUT_DIR` when set.
